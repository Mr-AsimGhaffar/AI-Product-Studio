# AI Product Studio

**AI-powered product photography for modern e-commerce businesses.**

AI Product Studio helps e-commerce businesses create professional product visuals and AI-generated model photography without arranging expensive photoshoots for every product design.

The goal is to make product photography more accessible, reduce production costs, and help businesses create marketplace-ready product content faster.

🌐 **Live Demo:** https://ai-e-commerce-product-studio.vercel.app

---

## 🎯 The Problem

Traditional e-commerce product photography often requires:

- Hiring professional models.
- Booking photography studios.
- Arranging photographers and equipment.
- Organizing multiple photoshoots for different product designs, colors, and angles.
- Spending additional time and money editing product images.

These expenses can become a challenge for small businesses, online sellers, and production studios that regularly manage large product catalogs.

## 💡 The Solution

AI Product Studio simplifies this process through an AI-powered workflow.

Users can provide product details, select their preferred visual style, configure model and photography settings, and generate product images using AI.

Instead of arranging a complete photoshoot for every design, businesses can create product visuals through a single streamlined workflow.

## ✨ Key Features

- **AI Product Photography** – Generate product visuals using AI.
- **AI Model Photography** – Create model-based product images for fashion and e-commerce catalogs.
- **Custom Creative Direction** – Configure product style, material, model appearance, backgrounds, and photography preferences.
- **Color Variations** – Generate visuals for different product colors.
- **Multiple Photography Angles** – Configure front, back, and multiple-angle product views.
- **Reference Images** – Use inspiration images to guide the visual generation process.
- **Marketplace-Oriented Output** – Prepare product content for platforms such as Amazon, eBay, Etsy, Daraz, and online stores.
- **Image Library** – Review generated images and their details.
- **Generation Estimation** – See the estimated image count based on selected options before generating.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm, yarn, or pnpm
- Cloudflare account and AI credentials

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd ai-product-studio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure environment variables.

   Create a `.env.local` file in the project root and add the required Cloudflare AI configuration:

   ```env
   CFARE_API_KEY=your_cloudflare_api_key
   ```

   Add any other environment variables required by your project configuration.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📸 How It Works

1. **Define Your Product** – Enter product details such as category, material, style, gender, and colors.
2. **Choose Creative Direction** – Configure the desired photography style, model appearance, background, and image angles.
3. **Configure Output** – Select image quantity, quality, and target marketplaces.
4. **Generate Images** – Use AI to generate product visuals based on your configuration.
5. **Review Results** – Browse generated images and review the output.
